# Previews

One folder per business: `previews/<business-slug>/index.html`.
Each preview is a single self-contained HTML page with a visible banner at the top:
"Preview made by 619 Sites. Not [Business]'s live website."
Every preview page also carries `<meta name="robots" content="noindex, nofollow">`.
Live address: https://619-sites.netlify.app/previews/<business-slug>/
