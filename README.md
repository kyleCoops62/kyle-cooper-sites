# kyle-cooper-sites

Websites built by Kyle Cooper for small San Diego businesses.

- `index.html`: portfolio sample site (Seabright Pool Care, a fictional business)
- `previews/<slug>/`: free previews sent to interested businesses (not indexed by search engines)
- `clients/<slug>/`: finished sites for paying clients

Hosted on Netlify (project `kyle-cooper-sites`), which publishes automatically on every push to `main`.
