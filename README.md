# kyle-cooper-sites

Kyle Cooper Web Design: websites built by Kyle Cooper for small San Diego businesses.

- `index.html`: Kyle Cooper Web Design home page (services, pricing, contact, policies)
- `sample/`: portfolio sample site (Seabright Pool Care, a fictional business)
- `previews/<slug>/`: free previews sent to interested businesses (not indexed by search engines)
- `clients/<slug>/`: finished sites for paying clients

Hosted on Netlify (project `kyle-cooper-web-design`, https://kyle-cooper-web-design.netlify.app), which publishes automatically on every push to `main`.
